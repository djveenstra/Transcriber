## Required implementation

- Versioned store root/path containment and opaque-ID validation.
- Codable v1 envelope, manifest generation, typed references, and pointer records sufficient for Phase 1.
- Immutable artifact write using same-filesystem temporary staging, close/synchronization, validation, SHA-256 digest, and atomic final placement.
- Pointer-authoritative manifest publication with expected-generation comparison and `current.previous` fallback.
- Reads that fail closed on unknown version, digest mismatch, traversal, wrong recording, corrupt pointer/manifest, and missing payload.
- Orphan/temp identification and conservative cleanup limited to proven unpublished material; corrupt/unknown state blocks destructive cleanup.
- Tests for round trip, legacy-only/no-store read, unknown version, corrupt payload/envelope/manifest/pointer, interrupted write/pointer failure, stale generation, traversal/cross-recording reference, previous-pointer fallback, rollback compatibility, and cleanup protection.
