# VX-06 — Persistent Processing Jobs and Relaunch Recovery

Status: Complete

Risk tier: Critical

Target app: Transcriber Mac

Manager: Codex

Approved to start by Daniel: Yes — sequential Phase 1 authorization on 2026-07-29

## Mission

Persist honest processing-job state and reconcile interrupted work after relaunch without allowing stale attempts to overwrite newer attempts, corrections, transcripts, or audio.

## Why now

- Prerequisites: VX-04 and VX-05 `PROCEED`.
- Primary risks: R-01, R-02, and R-04.
- Approved design: optional durable recording/source IDs, file-backed versioned jobs, artifact-evidenced success, and interrupted-on-relaunch semantics from VX-03.

## Required implementation

- Add only VX-03-approved optional random `processingRecordID` and `sourceAudioID` fields with nil-safe old-record compatibility.
- Assign missing IDs together and save them before any job file; retry reuses saved IDs.
- Versioned file-backed job records with job/run/attempt IDs, recording/source IDs, requested operation, input manifest generation, stage, timestamps, state, and published output references.
- Atomic job writes and safe decode/corruption behavior.
- Relaunch reconciliation maps stale `running`/`cancelRequested` to `interrupted`, never `succeeded`.
- `succeeded` requires valid published output evidence; current legacy-only results may be `partial` rather than falsely succeeded.
- Compare-before-update/publish prevents older attempts or stale input generations from overwriting a newer job/correction.
- Integrate major current processing/retry/cancel/failure checkpoints without weakening existing persist-before-process behavior.
- Reconcile to existing retry/partial-success UI projections; do not create a new UI system.

## Required tests

- Optional-field legacy compatibility and round trip.
- Identity-save failure creates no job; interrupted retry reuses IDs.
- Queued/running/cancelRequested/interrupted/partial/failed/succeeded state rules.
- Atomic/corrupt/unknown job files.
- Relaunch recovery and idempotence.
- Stale attempt/input generation/correction precondition rejection.
- Success without valid published artifact rejection.
- Cancel/failure preserves audio/last transcript and retry flags.
- Old-record playback/export/transcript decode regression.

## Validation

Run Mac build, full `TranscriberTests`, focused job/recovery/schema/cancellation suites, diff scope, strict concurrency, pins, and rollback/old-record evidence.

## Rollback

Old builds ignore optional fields and continue reading legacy blobs. Disable job writes/recovery and remove the job infrastructure; keep optional IDs harmless and preserved. No original audio or transcript transformation occurs.
