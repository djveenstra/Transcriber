## Technical approach

Capture reproducible commands and observed outputs in a baseline evidence file. Define the benchmark as a manifest-and-ground-truth contract that references private files outside Git, records provenance and consent, supports held-out cases, and keeps audio absent from reports by default. Resource evidence is limited to build/test process measurements and static system capacity because real-model inference would require approved recordings or downloads.

## Data and migration

- Existing data read path: not accessed.
- New data/write path: documentation only.
- Versioning: baseline snapshot and benchmark charter carry explicit version/date fields.
- Corruption behavior: the future harness must reject malformed manifests and ground truth without touching source audio.
- Rollback compatibility: remove the added documentation and restore governance pointers; no application data is written.
- User-data deletion: none.
